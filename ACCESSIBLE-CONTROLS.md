# Accessible controls

Existing keyboard, mouse and touch controls remain available throughout all campaign routes, personal stories, Last Refusal and Survive the Undead. Press **H** or **F1**, or select **CONTROLS**, for a chapter-aware guide. Opening the guide freezes the game and pauses tracked audio; closing it returns to the same scene. Escape closes the guide without leaving the chapter.

| Action | Original controls | Added alternative |
| --- | --- | --- |
| Movement / steering | WASD | Arrow keys |
| Aim / look | Mouse or touch swipe | I up, J left, K down, L right |
| Shoot / chain attack | Left-click or touch FIRE | Z, hold to repeat |
| Interact / heal | E | Enter, only when the action is available |
| Reload | R | X |
| Sprint | Shift | Either Shift, or T to toggle |
| Crouch | C | U to toggle |
| Dodge | Q | Space if the chapter has no jump/brake action |
| Map | Tab | M to toggle |
| Camera | V | B |
| Fly / land | F | G |
| Rise / descend | Chapter-specific keys | Page Up / Page Down |
| Pause / resume | Escape and pause buttons | P |
| Controls guide | On-screen button | H or F1 |

The guide provides saved look sensitivity, larger touch targets, and an optional tap-to-toggle RUN/CROUCH setting. Toggle states clear on pause, scene changes, guide opening, app switching, or loss of focus. Maps and quick-time prompts retain their original rules. Shortcuts are disabled during text entry and do not select story choices automatically. Menus support native Tab / Shift+Tab focus navigation and Enter / Space activation.

Keyboard look avoids pointer-lock requirements; mouse aiming retains the existing capture behaviour. Z, left-click, recoil animations and music choices are unchanged.
